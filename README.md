# Task 4 - Machine Learning Model Implementation

## Spam Email Detection using Scikit-learn

This internship project demonstrates binary text classification using TF-IDF and Logistic Regression.

### Files
- `Task_4_Spam_Email_Detection_FINAL.ipynb` — complete notebook
- `spam_dataset.csv` — dataset used by the notebook
- `requirements.txt` — Python dependencies

### Run
1. Install dependencies: `pip install -r requirements.txt`
2. Open the notebook in Jupyter or VS Code.
3. Select a Python kernel.
4. Use **Restart Kernel → Run All**.
